# Puzzle Wall

For my final project in my Microcomputer Project Laboratory class, I designed and built a puzzle wall! This is a prototype of a type of puzzle wall that I would eventually want to install in my own home, prompting the user with a variety of challenges, codes, etc. that the user can interact with by using the 'bricks' themselves as buttons.

The entire wall is mounted on a giant, hidden hinge (as can be seen in the image below), making it essentially a giant door that can be unlocked by solving different puzzles!

![](https://eden-hen.github.io/pages/PuzzleWall/hinge.jpeg)

Current functionality includes basic user identification and passcode storage, as well as game modes such as Simon Says or Snake.
